# MySQL Assignments

A collection of MySQL assignments and hands-on exercises supporting my AI-driven data analytics learning. This repository tracks my progress from foundational SQL queries to relational data modeling and analytics-ready database work.

## Learning Scope

- **SQL foundations:** databases, tables, data types, and basic `SELECT` queries
- **Filtering and sorting:** `WHERE`, `ORDER BY`, `LIMIT`, pattern matching, and `NULL` handling
- **Data changes:** `INSERT`, `UPDATE`, and `DELETE`, with careful validation of affected rows
- **Joins and relationships:** inner and outer joins, keys, and combining related datasets
- **Aggregation:** aggregate functions, `GROUP BY`, and `HAVING` for summaries and business metrics
- **Advanced queries:** subqueries, common table expressions (CTEs), and window functions
- **Schema design:** primary and foreign keys, constraints, normalization, and referential integrity
- **Database performance:** indexes, query plans, and the tradeoffs of indexing
- **Reliable data operations:** transactions, commits, rollbacks, and handling data consistently
- **Reusable database objects:** views and, where assignments require them, stored procedures and triggers
- **Analytics practice:** preparing, validating, and documenting datasets for reporting and downstream analysis

## Assignment Contents

Assignments may include:

- A problem statement and expected output
- Schema and table creation scripts
- Sample or source data, where sharing is appropriate
- SQL queries with explanations
- Validation checks and expected results
- Notes on assumptions, edge cases, and performance

## Suggested Structure

| Path | Purpose |
| --- | --- |
| `assignments/` | Assignment-specific prompts, solutions, and notes |
| `data/` | Sample datasets used in exercises |
| `scripts/` | Reusable schema, setup, and query scripts |
| `docs/` | Learning notes and supporting documentation |

## Getting Started

1. Install MySQL 8.0 or a compatible MySQL client/server environment.
2. Open an assignment folder and review its prompt and setup instructions.
3. Run the provided schema or data setup scripts in a development database.
4. Execute and validate the queries, then compare the results with the assignment requirements.

Use a local development database for exercises. Review scripts before running statements that modify or remove data, and do not commit credentials or private datasets.
